# v0.18-C — Resource and feedback polish

The physical resource loop now uses the same authored visual language as the v0.18 world.

## Integrated
- Dedicated fallen-tree and stump assets.
- Dedicated log and stone pickup assets.
- Authored cargo frame behind the hero with visible carried items.
- Authored stockpiles near the Hearth/workshop.
- Pickup and unload flight visuals use the same resource sprites.
- Small pitch variation prevents repeated chopping/pickup sounds from feeling identical.
- Resource unloading has its own sound cue.
- Finished hub buildings and the expedition workshop get a stronger completion payoff.

## Preserved
- Existing carry limits and economy.
- One-by-one unloading.
- Tree-fall timing and physical pickup loop.
- Mobile controls, combat, route structure and progression.
