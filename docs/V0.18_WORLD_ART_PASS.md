# v0.18-B — Forgotten Forest world-art integration

This pass closes the visual gap between the approved Package 5 direction and the playable Godot build.

## Integrated
- Harvestable trees now use a dedicated v0.18 authored forest set.
- The large play space is composed from independent transparent assets; no full-screen background image is used.
- Forest edges, ground patches, ferns, bushes and rock clusters create depth and a coherent location.
- Hearth levels 3–5 are dedicated authored stages instead of procedural geometry.
- Completed resident homes, the expedition workshop and watchtower use authored assets.
- Existing hero/NPC/enemy art, movement, routes, progression and mobile controls remain intact.

## Visual rules
- One hero scale and one ground anchor.
- Warm, soft Forgotten Forest palette.
- Hearth stays the strongest warm visual anchor.
- World art supports navigation and never replaces gameplay.
- Central routes stay readable on a phone.
