# Last Hearth / Последний Очаг

Standalone Godot project for the second game.

## Current restored foundation

This repository contains the clean Last Hearth prototype from before it was mixed with AXEHOLD:

- hearth-centered survival loop;
- wood and stone gathering;
- three days and three nights;
- survivors;
- workshop choice;
- watchtower;
- elite enemies and the Forest Guardian boss;
- physical boss-core return to the hearth;
- persistent hub and saved ember upgrades;
- randomized expedition layout between attempts;
- floating touch joystick.

AXEHOLD is a separate project and must not be developed in this repository.

## Web build

GitHub Actions validates the Godot project, exports the Web build and deploys it to GitHub Pages.
