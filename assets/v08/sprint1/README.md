# Last Hearth v0.8 — Sprint 1 Production Asset Pack

This folder is the first production-asset pass for the visual rebuild.

## Included
- Hero: idle, walk, axe attack, carry 1/2/3 logs.
- Trees: three living variants, falling tree, stump.
- Resources: log, rock, grass.
- Hearth: dedicated Level I and Level II art.

## Runtime use
The assets are SVG textures imported directly by Godot 4. They replace procedural hero/tree/log/hearth drawing in the opening loop while later-game art keeps the v0.7 fallback until the next visual-rebuild sprints.

## Visual rules
- warm cream/brown hero palette;
- muted forest greens;
- amber firelight;
- transparent backgrounds;
- readable silhouettes at mobile scale;
- no text baked into production sprites.
